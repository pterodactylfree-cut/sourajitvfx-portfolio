# SourajitVFX — Developer Portfolio

A responsive dark-neon portfolio built with plain HTML, CSS, and JavaScript. The site is self-contained in `index.html`, so it needs no build command, package installation, or framework preset.

## Deploy on Vercel
1. Import `Rdx690/sourajitvfx-portfolio` into Vercel.
2. Select **Other** as the framework preset.
3. Leave Build Command and Install Command empty.
4. Set Output Directory to `.` (or leave it blank if Vercel auto-detects the static site).
5. Deploy.
